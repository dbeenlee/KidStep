# 幼小衔接能力培养清单

## 家长自查清单

> 入学前对照检查，**大部分能做到即准备充分**。

---

## 一、身心准备 ✅

- [ ] 对小学生活有期待，不害怕上学
- [ ] 能表达自己的情绪（"我有点紧张""我需要帮助"）
- [ ] 有一定的运动能力和身体协调性
- [ ] 手部精细动作发展良好（剪纸、穿珠子、握笔）

### 训练方法
| 能力 | 活动 | 说明 |
|------|------|------|
| 积极期待 | 参观小学、读相关绘本 | 消除陌生感 |
| 情绪表达 | 情绪卡片、"我生气时..."讨论 | 用语言表达感受 |
| 运动能力 | 跳绳、跑步、拍球 | 每天1-2小时户外 |
| 精细动作 | 剪纸、橡皮泥、连线迷宫 | 为握笔做准备 |

---

## 二、生活准备 ✅

- [ ] 能按时起床、睡觉，作息基本规律
- [ ] 会自己穿衣、系鞋带（或魔术贴鞋）
- [ ] 自己整理书包、整理文具
- [ ] 能独立上厕所，饭前便后洗手
- [ ] 熟练使用筷子，不挑食，规定时间内吃完
- [ ] 掌握简单劳动（扫地、擦桌子）

### 训练方法
| 技能 | 活动 | 工具 |
|------|------|------|
| 作息调整 | 模拟上学时间表 | 沙漏、计时器 |
| 自理能力 | "我是生活小能手"练习 | 打卡表 |
| 时间管理 | 可视化作息表 | 磁贴地图 |
| 整理习惯 | 整理书包比赛 | 收纳盒 |

---

## 三、社会准备 ✅

- [ ] 知道上课要举手发言
- [ ] 能遵守基本规则（排队、轮流）
- [ ] 会用礼貌用语（请、谢谢、对不起）
- [ ] 愿意和同伴交往，能分享玩具
- [ ] 能记住老师交代的简单任务
- [ ] 游戏输了不会大发脾气

### 训练方法
| 能力 | 活动 | 说明 |
|------|------|------|
| 规则意识 | 家庭课堂模拟 | 角色扮演 |
| 社交技能 | "我能和你一起玩吗"练习 | 情景演练 |
| 合作能力 | 拼图、积木合作搭建 | 多人游戏 |
| 抗挫能力 | 棋类游戏体验输赢 | 五子棋、飞行棋 |
| 任务意识 | "帮妈妈把...拿到..." | 指令执行 |

---

## 四、学习准备 ✅

- [ ] 对阅读有兴趣，能静坐听故事15-20分钟
- [ ] 有好奇心，喜欢问"为什么"
- [ ] 会握笔，能坐得住
- [ ] 在生活中对数字、形状有兴趣
- [ ] 能听懂并记住2-3个连续指令
- [ ] 有时间概念（整点、5分钟）

### 训练方法
| 能力 | 活动 | 说明 |
|------|------|------|
| 专注力 | 舒尔特方格、定时阅读 | 15-20分钟开始 |
| 倾听习惯 | 指令游戏、"举左手举右手" | 听觉专注 |
| 阅读习惯 | 每日亲子共读15-20分钟 | 指读 |
| 书写准备 | 连线、迷宫、涂色 | 控笔训练 |
| 数感培养 | 指物数数、超市购物 | 生活渗透 |
| 空间感知 | 积木、图形找朋友 | 图形认知 |

---

## 五、学科专项准备

### 语文
- [ ] 坚持每日亲子阅读
- [ ] 能复述简单故事
- [ ] 握笔姿势正确
- [ ] 在生活中自然接触汉字

### 数学
- [ ] 熟练10以内数的分解与组合
- [ ] 能进行简单比较（大小、高矮）
- [ ] 认识基本平面图形
- [ ] 有时间（整点半点）和货币概念

### 英语
- [ ] 愿意听英文儿歌/看英文动画
- [ ] 会简单问候语
- [ ] 对英语不排斥、有兴趣

---

## 评估标准

| 维度 | 优秀 | 良好 | 合格 | 需提高 |
|------|------|------|------|--------|
| 身心 | 全部做到 | 4/5 | 3/5 | <3/5 |
| 生活 | 全部做到 | 5/6 | 4/6 | <4/6 |
| 社会 | 全部做到 | 5/6 | 4/6 | <4/6 |
| 学习 | 全部做到 | 5/6 | 4/6 | <4/6 |
