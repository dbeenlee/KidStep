# 幼小衔接学科知识体系

## 总体目标

按"必须掌握 / 建议掌握 / 可选拓展"三级分类，**重兴趣轻灌输**。

---

## 一、语文

### 目标等级

| 等级 | 内容 | 说明 |
|------|------|------|
| 必须掌握 | 拼音声母、韵母、整体认读音节；认识约690个常用汉字；能书写约300个汉字；正确朗读课文 | 新课标：一二年级认识1600字，一年级690字 |
| 建议掌握 | 识300-400字并运用；积累常用词语；复述小故事；背诵古诗词3-5首 | 如《咏鹅》《静夜思》 |
| 可选拓展 | 阅读绘本/桥梁书；写简单日记(2-3句)；学习楷书偏旁结构 | 兴趣培养 |

### 核心能力
- **前书写能力**：握笔姿势、控笔能力（连线、迷宫、涂色）
- **拼音启蒙**：听音、拼读，不强求默写
- **阅读习惯**：亲子共读，指读，在阅读中自然识字
- **表达训练**：完整句子表达，复述故事

### 推荐绘本
- 《大卫上学去》《小阿力的大学校》《一年级没问题》
- 拼音识字绘本

## 二、数学

### 目标等级

| 等级 | 内容 |
|------|------|
| 必须掌握 | 写读1-100；10以内加减法；认识基本几何图形；比较大小、长短；认识整点 |
| 建议掌握 | 10以内连加连减；认识100结构；分辨方向；简单度量单位；分类排序规律 |
| 可选拓展 | 100以内加减法；乘除启蒙（分组/平均分）；简单货币认识 |

### 核心能力
- **数感**：数量守恒、基数概念
- **逻辑思维**：分类、排序、找规律
- **空间感知**：平面/立体图形、方位
- **生活中的数学**：超市购物、分配餐具、认识日历

### 推荐活动
- 指物数数
- 魔法积木变变变（数量守恒）
- 家庭分餐（加减法）
- 动物腿数猜猜猜（逻辑推理）

## 三、英语（兴趣与语感为主）

### 目标等级

| 等级 | 内容 |
|------|------|
| 必须掌握 | 26个字母；5-10个问候语；数字1-10；基础颜色词；听懂简单指令 |
| 建议掌握 | 词汇量50词；简单需求表达；跟读儿歌；CVC单词拼读 |
| 可选拓展 | 双语绘本；数字11-20；星期月份 |

### 核心方法
- **磨耳朵**：英文儿歌、原版动画（Peppa Pig）
- **游戏化**：我说你指（Point to the door!）
- **不要求**：背单词、学语法

## 四、科学

### 目标等级

| 等级 | 内容 |
|------|------|
| 必须掌握 | 认识身体结构；安全常识；常见动植物；提出问题并观察 |
| 建议掌握 | 天气/四季；材料分类；观察记录（画图） |
| 可选拓展 | 磁铁原理；植物生长观察；简单机器原理 |

### 核心能力
- 观察身边事物
- 提出问题
- 简单实验（叶子浮沉、水溶解）

## 五、品德与社会

### 目标等级

| 等级 | 内容 |
|------|------|
| 必须掌握 | 尊重师长；守规矩；基本自律；分享合作；公共秩序 |

## 六、艺术与体育

### 艺术
| 等级 | 内容 |
|------|------|
| 必须掌握 | 使用画材；认识基本色彩；剪纸拼贴；唱儿歌童谣 |
| 建议掌握 | 节奏感；简单乐理（音符）；舞蹈戏剧元素 |
| 可选拓展 | 简单器乐（口风琴）；手工制作 |

### 体育
| 等级 | 内容 |
|------|------|
| 必须掌握 | 跑跳投接基本动作；遵守规则；跳绳、拍球；讲卫生 |
| 建议掌握 | 平衡柔韧；团队游戏 |
| 可选拓展 | 游泳、轮滑安全知识 |

### 每日目标
- 户外活动30分钟-2小时
- 跳绳（很多学校有考核）

## 七、学习习惯与元认知

| 能力 | 目标 | 训练方法 |
|------|------|---------|
| **专注力** | 15-20分钟专注 | 舒尔特方格；定时任务 |
| **倾听能力** | 听懂2-3个连续指令 | 指令游戏；复述故事 |
| **时间观念** | 认识整点半点；5/10分钟概念 | 沙漏；可视化打卡表 |
| **作业习惯** | 按时完成、自我检查 | 分解任务、逐步放手 |
| **规则意识** | 举手发言、接受输赢 | 棋类游戏、角色扮演 |
