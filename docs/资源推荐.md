## 四、实用工具

### 专注力训练
- **舒尔特方格**：5x5数字网格，按顺序指读
- **走迷宫**：锻炼视觉追踪
- **连线游戏**：数字/字母连线

### 情绪管理
- **情绪卡片**：喜怒哀乐等表情
- **情绪角**：安全的情绪表达空间

### 奖励系统
- **任务存折**：积分兑换奖励
- **成长树**：可视化进步
- **打卡表**：每日坚持记录

## 五、注意事项

### 选择原则
1. **适龄性**：符合6-7岁认知水平
2. **趣味性**：游戏化而非刷题
3. **安全性**：材质安全、内容健康
4. **教育性**：有明确学习目标

### 使用建议
- 每次使用15-30分钟
- 以游戏为主，避免强制
- 关注兴趣而非结果
- 定期轮换保持新鲜感
