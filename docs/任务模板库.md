# 幼小衔接训练任务模板库

> 共 50 个任务模板，覆盖三阶段 × 四维度 × 四类型 × 三难度的组合。
> 供程序读取后按阶段、维度自动组装为每日训练计划。

---

## 类型说明

| 字段 | 含义 | 可选值 |
|------|------|--------|
| type | 任务类型 | `HABIT`(习惯打卡) / `ABILITY`(能力训练) / `BONDING`(亲子互动) / `KNOWLEDGE`(知识学习) |
| dimension | 能力维度 | `PHYSICAL`(身心) / `LIFE`(生活) / `SOCIAL`(社会) / `LEARNING`(学习) |
| phase | 适用阶段 | `PHASE_1`(入学前3月) / `PHASE_2`(入学前1月) / `PHASE_3`(入学前2周) / `ALL`(全阶段通用) |
| difficulty | 难度等级 | `1`(入门) / `2`(进阶) / `3`(挑战) |
| duration | 预计时长 | 单位：分钟 |
