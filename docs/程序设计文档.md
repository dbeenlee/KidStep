## 一、项目概述

### 1.1 项目背景

随着教育部《幼儿园与小学科学衔接指导意见》和2022年版新课标的实施，幼小衔接成为幼儿园大班家长最关注的话题。

**核心痛点**：
- 家长缺乏系统的幼小衔接知识
- 不知如何科学评估孩子准备情况
- 没有合适的工具跟踪孩子成长
- 难以坚持长期的家庭训练计划

### 1.2 项目目标

打造一款帮助**幼儿园大班家长**科学开展幼小衔接的辅助工具。

**核心定位**：家长是设计者，系统是执行者，孩子是被服务者。

### 1.3 核心功能

1. **知识库**：系统化的幼小衔接知识体系
2. **评估工具**：孩子能力自评与进度跟踪
3. **训练计划**：三阶段家庭训练方案
4. **打卡系统**：每日任务打卡与习惯养成
5. **成长档案**：记录孩子成长轨迹

### 1.4 设计原则

| 原则 | 说明 |
|------|------|
| **主动推送 > 被动查询** | 系统按规则主动安排任务，用户不需要想"今天做什么" |
| **极简操作** | ≤3步完成一个动作，3秒完成打卡 |
| **单任务模式** | 每次只展示1个待办任务，完成后展示下一个 |
| **积分即反馈** | 只奖不扣，每次努力都被记录和看见 |
| **数据驾驶舱** | 让进步可视化，打开就能看清状态 |

## 二、功能模块

### 2.1 知识中心

#### 2.1.1 知识分类

| 分类 | 内容 |
|------|------|
| 核心概念 | 零起点≠零准备、四个准备维度、新课标解读 |
| 能力清单 | 身心/生活/社会/学习准备详细清单 |
| 学科指导 | 语文/数学/英语/科学/艺术体育的具体要求 |
| 家长指南 | 三阶段训练方案、游戏化训练方法 |
| 资源推荐 | 书单/APP/教具推荐 |

#### 2.1.2 功能点
- 知识文章浏览（支持收藏）
- 关键词搜索
- 分享功能

### 2.2 能力评估

#### 2.2.1 评估维度

| 维度 | 评估项目 |
|------|---------|
| 身心准备 | 期待/信心、情绪表达、运动能力、精细动作 |
| 生活准备 | 作息规律、自理能力、卫生习惯、劳动技能 |
| 社会准备 | 规则意识、合作分享、礼貌用语、任务执行 |
| 学习准备 | 专注力、倾听习惯、阅读兴趣、数感基础 |

#### 2.2.2 功能点
- 周期性自评问卷（每周/每月）
- 可视化雷达图展示
- 历史对比（进步追踪）
- 个性化建议生成

### 2.3 训练计划

#### 2.3.1 三阶段计划

| 阶段 | 时间 | 重点 | 任务数/天 |
|------|------|------|----------|
| 第一阶段 | 入学前3个月 | 习惯建立、兴趣培养 | 3-5个 |
| 第二阶段 | 入学前1个月 | 知识巩固、模拟训练 | 4-6个 |
| 第三阶段 | 入学前2周 | 作息调整、心理准备 | 5-8个 |

#### 2.3.2 功能点
- 自动生成阶段性任务
- 每日任务推送（单任务模式）
- 任务完成打卡
- 进度可视化

### 2.4 每日打卡

#### 2.4.1 打卡项目

| 类型 | 项目 |
|------|------|
| 习惯类 | 作息打卡、运动打卡、阅读打卡 |
| 能力类 | 专注力训练、数学游戏、社交练习 |
| 亲子类 | 亲子阅读、亲子游戏 |

#### 2.4.2 功能点
- 快速打卡（3秒完成）
- 打卡日历热力图
- 连续打卡激励（积分只奖不扣）
- 统计数据导出

### 2.5 成长档案

#### 2.5.1 记录类型
- 文字记录（里程碑事件）
- 照片上传（能力展示）
- 评估记录（历史数据）
- 收藏内容（知识/资源）

#### 2.5.2 功能点
- 时间轴展示
- 成长报告生成（PDF导出）
- 入学准备度报告

## 三、技术架构

### 3.1 技术选型

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端框架 | **Next.js 14** (App Router) | React SSR，SEO友好，适合内容型产品 |
| UI组件 | **shadcn/ui** | 基于Radix + Tailwind，可定制性强 |
| 样式 | **Tailwind CSS** | 快速开发 |
| 图表 | **Recharts** | 雷达图、折线图、柱状图 |
| 状态管理 | **Zustand** | 轻量级客户端状态 |
| 后端 | **Next.js API Routes** | 快速原型，后续可拆分 |
| 数据库 | **PostgreSQL** (Supabase) | 免费额度够用，支持实时订阅 |
| ORM | **Prisma** | 类型安全，迁移方便 |
| 认证 | **NextAuth.js v5** | JWT策略，支持手机号+验证码 |
| 部署 | **Vercel** | 免费额度够用，CDN加速 |
| 短信 | **阿里云SMS** | 验证码发送 |

## 五、数据模型（Prisma Schema）

### 5.1 完整 Schema

```prisma
// prisma/schema.prisma

generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider  = "postgresql"
  url       = env("DATABASE_URL")
  directUrl = env("DIRECT_URL")
}

// ==================== 枚举类型 ====================

enum Gender {
  MALE
  FEMALE
  UNKNOWN
}

enum Dimension {
  PHYSICAL   // 身心准备
  LIFE       // 生活准备
  SOCIAL     // 社会准备
  LEARNING   // 学习准备
}

enum TaskType {
  HABIT      // 习惯打卡（作息/运动/阅读）
  ABILITY    // 能力训练（专注力/数学/社交）
  BONDING    // 亲子互动（亲子阅读/游戏）
  KNOWLEDGE  // 知识学习（阅读文章）
}

enum TaskStatus {
  PENDING
  COMPLETED
  SKIPPED
}

enum TrainingPhase {
  PHASE_1    // 入学前3个月
  PHASE_2    // 入学前1个月
  PHASE_3    // 入学前2周
}

enum MilestoneType {
  TEXT
  PHOTO
  ASSESSMENT
}

enum ArticleCategory {
  CONCEPT     // 核心概念
  CHECKLIST   // 能力清单
  SUBJECT     // 学科指导
  GUIDE       // 家长指南
  FAQ         // 常见问题
}

enum PointSource {
  CHECKIN       // 打卡
  ASSESSMENT    // 完成评估
  MILESTONE     // 记录里程碑
  STREAK        // 连续打卡奖励
}

// ==================== 数据模型 ====================

/// 用户表
model User {
  id        String   @id @default(cuid())
  phone     String   @unique
  nickname  String?
  avatar    String?
  createdAt DateTime @default(now()) @map("created_at")
  updatedAt DateTime @updatedAt @map("updated_at")

  children  Child[]
  favorites Favorite[]

  @@map("users")
}

/// 孩子表
model Child {
  id           String   @id @default(cuid())
  userId       String   @map("user_id")
  name         String
  birthday     DateTime @db.Date
  gender       Gender   @default(UNKNOWN)
  targetSchool String?  @map("target_school")
  createdAt    DateTime @default(now()) @map("created_at")
  updatedAt    DateTime @updatedAt @map("updated_at")

  user         User         @relation(fields: [userId], references: [id], onDelete: Cascade)
  assessments  Assessment[]
  checkins     Checkin[]
  tasks        Task[]
  points       Point[]
  milestones   Milestone[]

  @@map("children")
}

/// 评估记录表
model Assessment {
  id        String    @id @default(cuid())
  childId   String    @map("child_id")
  dimension Dimension
  score     Int                            // 该维度得分（0-100）
  answers   Json                           // 每题的选项和得分 [{questionId, optionKey, score}]
  report    Json?                          // 评估报告 {strengths, weaknesses, suggestions}
  createdAt DateTime  @default(now()) @map("created_at")

  child     Child     @relation(fields: [childId], references: [id], onDelete: Cascade)

  @@index([childId, createdAt])
  @@map("assessments")
}

/// 打卡记录表
model Checkin {
  id        String   @id @default(cuid())
  childId   String   @map("child_id")
  date      DateTime @db.Date
  type      TaskType
  itemName  String   @map("item_name")       // 打卡项名称（如"早起打卡"）
  note      String?
  createdAt DateTime @default(now()) @map("created_at")

  child     Child    @relation(fields: [childId], references: [id], onDelete: Cascade)

  @@unique([childId, date, type, itemName])
  @@index([childId, date])
  @@map("checkins")
}

/// 训练任务表（每日生成的实例）
model Task {
  id            String      @id @default(cuid())
  childId       String      @map("child_id")
  phase         TrainingPhase
  taskType      TaskType    @map("task_type")
  templateId    String      @map("template_id")  // 引用任务模板
  title         String
  description   String?
  duration      Int?                              // 预计时长（分钟）
  status        TaskStatus  @default(PENDING)
  scheduledDate DateTime    @db.Date @map("scheduled_date")
  completedAt   DateTime?   @map("completed_at")
  createdAt     DateTime    @default(now()) @map("created_at")

  child         Child       @relation(fields: [childId], references: [id], onDelete: Cascade)

  @@index([childId, scheduledDate])
  @@index([childId, status])
  @@map("tasks")
}

/// 积分记录表
model Point {
  id        String      @id @default(cuid())
  childId   String      @map("child_id")
  amount    Int                                   // 正数（只奖不扣）
  reason    String
  source    PointSource
  createdAt DateTime    @default(now()) @map("created_at")

  child     Child       @relation(fields: [childId], references: [id], onDelete: Cascade)

  @@index([childId, createdAt])
  @@map("points")
}

/// 成长记录表
model Milestone {
  id        String        @id @default(cuid())
  childId   String        @map("child_id")
  type      MilestoneType
  content   String?
  mediaUrls Json?         @map("media_urls")     // 图片URL数组
  createdAt DateTime      @default(now()) @map("created_at")

  child     Child         @relation(fields: [childId], references: [id], onDelete: Cascade)

  @@index([childId, createdAt])
  @@map("milestones")
}

/// 知识文章表
model Article {
  id        String          @id @default(cuid())
  category  ArticleCategory
  title     String
  content   String                                // Markdown 内容
  summary   String?
  coverUrl  String?         @map("cover_url")
  tags      Json?                                 // 标签数组
  views     Int             @default(0)
  likes     Int             @default(0)
  sortOrder Int             @default(0) @map("sort_order")
  createdAt DateTime        @default(now()) @map("created_at")
  updatedAt DateTime        @updatedAt @map("updated_at")

  favorites Favorite[]

  @@index([category])
  @@map("articles")
}

/// 收藏表
model Favorite {
  id        String   @id @default(cuid())
  userId    String   @map("user_id")
  articleId String   @map("article_id")
  createdAt DateTime @default(now()) @map("created_at")

  user      User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  article   Article  @relation(fields: [articleId], references: [id], onDelete: Cascade)

  @@unique([userId, articleId])
  @@map("favorites")
}

/// 短信验证码表
model SmsCode {
  id        String   @id @default(cuid())
  phone     String
  code      String
```

```typescript
import NextAuth from "next-auth"
import CredentialsProvider from "next-auth/providers/credentials"
import { db } from "@/lib/db"

export const { handlers, signIn, signOut, auth } = NextAuth({
  session: { strategy: "jwt" },
  providers: [
    CredentialsProvider({
      name: "phone",
      credentials: {
        phone: { label: "手机号", type: "text" },
        code: { label: "验证码", type: "text" },
      },
      async authorize(credentials) {
        const { phone, code } = credentials as { phone: string; code: string }

        // 验证短信验证码
        const smsCode = await db.smsCode.findFirst({
          where: {
            phone,
            code,
            used: false,
            expiresAt: { gt: new Date() },
          },
        })
        if (!smsCode) return null

        // 标记已使用
        await db.smsCode.update({
          where: { id: smsCode.id },
          data: { used: true },
        })

        // 查找或创建用户
        const user = await db.user.upsert({
          where: { phone },
          create: { phone },
          update: {},
        })

        return { id: user.id, phone: user.phone, name: user.nickname }
      },
    }),
  ],
  callbacks: {
    async jwt({ token, user }) {
      if (user) {
        token.userId = user.id
      }
      return token
    },
    async session({ session, token }) {
      session.user.id = token.userId as string
      return session
    },
  },
})
```

### 8.2 评估评分算法

```typescript
// src/lib/scoring.ts

interface QuizAnswer {
  questionId: string
  optionKey: string  // A/B/C/D
  score: number      // 该选项得分 0-5
}

interface AssessmentResult {
  dimension: Dimension
  score: number            // 0-100 归一化分数
  answers: QuizAnswer[]
  report: {
    strengths: string[]    // 得分最高的2-3个能力项
    weaknesses: string[]   // 得分最低的2-3个能力项
    suggestions: string[]  // 3-5条改进建议
  }
}

/**
 * 计算评估得分
 * 每题满分5分，10题满分50分，归一化到100分制
 */
function calculateScore(answers: QuizAnswer[]): number {
  const totalScore = answers.reduce((sum, a) => sum + a.score, 0)
  const maxScore = answers.length * 5
  return Math.round((totalScore / maxScore) * 100)
}

/**
 * 生成评估报告
 * 按题目分类（如"运动能力"、"精细动作"）聚合得分
 * 取得分最高/最低的子分类生成建议
 */
function generateReport(answers: QuizAnswer[], questions: Question[]): Report {
  // 按 category 聚合每题得分
  const categoryScores = groupBy(answers, a => {
    const q = questions.find(q => q.id === a.questionId)
    return q?.category ?? "other"
  })

  const sorted = Object.entries(categoryScores)
    .map(([cat, answers]) => ({
      category: cat,
      avgScore: average(answers.map(a => a.score)),
    }))
    .sort((a, b) => b.avgScore - a.avgScore)

  return {
    strengths: sorted.slice(0, 2).map(s => s.category),
    weaknesses: sorted.slice(-2).map(s => s.category),
    suggestions: generateSuggestions(sorted.slice(-2)),
  }
}
```

```typescript
// src/lib/taskGenerator.ts

/**
 * 为孩子生成今日任务
 * 调用时机：用户打开首页时，若今日无任务则自动生成
 */
async function generateTodayTasks(childId: string): Promise<Task[]> {
  // 1. 确定当前训练阶段（根据目标入学日期计算）
  const phase = getCurrentPhase(child.birthday)

  // 2. 获取最近一次评估的薄弱项
  const latestAssessment = await getLatestAssessment(childId)
  const weakDimensions = getWeakDimensions(latestAssessment)

  // 3. 获取已完成任务，避免连续重复
  const recentTasks = await getRecentCompletedTasks(childId, 7)
  const recentTemplateIds = recentTasks.map(t => t.templateId)

  // 4. 从模板库匹配任务
  const candidates = TASK_TEMPLATES
    .filter(t => t.phase === phase || t.phase === "ALL")
    .filter(t => !recentTemplateIds.includes(t.id))

  // 5. 按优先级排序：薄弱项优先
  const sorted = candidates.sort((a, b) => {
    const aWeak = weakDimensions.includes(a.dimension) ? 1 : 0
    const bWeak = weakDimensions.includes(b.dimension) ? 1 : 0
    return bWeak - aWeak
  })

  // 6. 取前N个任务（阶段决定数量）
  const count = { PHASE_1: 3, PHASE_2: 4, PHASE_3: 5 }[phase]

  // 7. 确保任务类型多样化（至少包含1个习惯+1个能力+1个亲子）
  const selected = diversifyTasks(sorted, count)

  // 8. 写入数据库
  return db.task.createMany({
    data: selected.map(t => ({
      childId,
      phase,
      taskType: t.type,
      templateId: t.id,
      title: t.title,
      description: t.description,
      duration: t.duration,
      scheduledDate: today(),
    })),
  })
}
```

### 8.4 积分系统

```typescript
// src/lib/pointsCalculator.ts

/**
 * 积分规则：只奖不扣
 */
const POINT_RULES = {
  /** 完成打卡 */
  checkin: 1,
  /** 完成训练任务 */
  taskComplete: 2,
  /** 完成一次评估 */
  assessment: 5,
  /** 记录里程碑 */
  milestone: 3,
  /** 连续打卡奖励：连续N天额外+N分（上限7） */
  streakBonus: (days: number) => Math.min(days, 7),
}

/**
 * 打卡时自动计算并发放积分
 */
async function awardCheckinPoints(childId: string): Promise<Point> {
  // 基础积分
  const basePoints = POINT_RULES.checkin

  // 计算连续打卡天数
  const streak = await calculateStreak(childId)
  const bonus = POINT_RULES.streakBonus(streak)

  const totalAmount = basePoints + bonus

  // 创建积分记录
  const point = await db.point.create({
    data: {
      childId,
      amount: totalAmount,
      reason: bonus > 0
        ? `打卡 +${basePoints}，连续${streak}天 +${bonus}`
        : `打卡 +${basePoints}`,
      source: bonus > 0 ? "STREAK" : "CHECKIN",
    },
  })

  return point
}

/**
 * 计算连续打卡天数
 */
async function calculateStreak(childId: string): Promise<number> {
  const checkins = await db.checkin.findMany({
    where: { childId },
    select: { date: true },
    distinct: ["date"],
    orderBy: { date: "desc" },
    take: 365,
  })

  let streak = 0
  let current = new Date()
  current.setHours(0, 0, 0, 0)

  for (const checkin of checkins) {
    const checkinDate = new Date(checkin.date)
    checkinDate.setHours(0, 0, 0, 0)

    const diffDays = Math.floor(
      (current.getTime() - checkinDate.getTime()) / (1000 * 60 * 60 * 24)
    )

    if (diffDays === streak) {
      streak++
    } else {
      break
    }
  }

  return streak
}
```

```typescript
// src/stores/useTaskStore.ts
import { create } from "zustand"

interface TaskStore {
  /** 今日任务队列 */
  queue: Task[]
  /** 当前展示的任务索引 */
  currentIndex: number
  /** 当前任务 */
  currentTask: Task | null
  /** 是否全部完成 */
  allDone: boolean

  /** 初始化任务队列 */
  initQueue: (tasks: Task[]) => void
  /** 完成当前任务，展示下一个 */
  completeAndNext: () => void
  /** 跳过当前任务，展示下一个 */
  skipAndNext: () => void
}

const useTaskStore = create<TaskStore>((set, get) => ({
  queue: [],
  currentIndex: 0,
  currentTask: null,
  allDone: false,

  initQueue: (tasks) => {
    const pending = tasks.filter(t => t.status === "PENDING")
    set({
      queue: pending,
      currentIndex: 0,
      currentTask: pending[0] ?? null,
      allDone: pending.length === 0,
    })
  },

  completeAndNext: () => {
    const { queue, currentIndex } = get()
    const nextIndex = currentIndex + 1
    set({
      currentIndex: nextIndex,
      currentTask: queue[nextIndex] ?? null,
      allDone: nextIndex >= queue.length,
    })
  },

  skipAndNext: () => {
    // 跳过逻辑同完成，但任务状态标记为SKIPPED
    get().completeAndNext()
  },
}))
```

## 十一、AI 能力配置（v1.1+ 可选）

> 基于"AI 能力应按需启用，配置必须可自定义"的原则

### 11.1 设计原则

| 原则 | 说明 |
|------|------|
| **按需启用** | MVP 不依赖 AI，用规则替代 |
| **可插拔** | AI 能力作为插件，随时可关闭 |
| **可配置** | 所有 AI 参数（API Key、模型、Prompt）都支持自定义 |
| **本地优先** | 优先使用本地/开源模型，节省成本 |
| **降级策略** | AI 不可用时自动降级到规则模式 |

### 11.2 AI 能力模块

#### 11.2.1 LLM 大模型

**用途**：生成个性化成长报告、智能任务推荐、AI 育儿问答助手

**支持提供商**：

| 提供商 | 说明 | 配置项 |
|--------|------|--------|
| **DeepSeek** | 性价比最高 | API Key、模型版本 |
| **OpenAI** | GPT-4o / GPT-4o-mini | API Key、模型版本 |
| **Claude** | Claude Sonnet | API Key、模型版本 |
| **本地模型** | Ollama / LM Studio | 本地地址、模型名称 |

#### 11.2.2 TTS 语音合成

**用途**：定时语音播报今日任务、知识文章朗读

**策略**：短文本（≤20字）用云端TTS，长文本用 Web Speech API

```typescript
// src/lib/ai/tts.ts
const useSmartAudio = () => {
  const play = (text: string) => {
    if (text.length <= 20 && process.env.TTS_ENABLED === "true") {
      playCloudTTS(text)
    } else {
      playWebSpeech(text)
    }
  }
}
```

### 11.3 降级策略

| AI 能力 | 正常模式 | 降级模式 |
|---------|---------|---------|
| **LLM** | AI 生成报告 | 固定模板 + 数据填充 |
| **TTS** | 云端合成 | Web Speech API → 纯文字展示 |

### 11.4 实施计划

| 阶段 | AI 能力 | 优先级 | 说明 |
|------|---------|:------:|------|
| MVP | 无 | - | 用规则替代 |
| v1.1 | TTS（Web Speech） | P1 | 浏览器免费实现 |
| v1.1 | LLM（DeepSeek） | P2 | 成长报告生成 |
| v1.2 | TTS（云端） | P1 | 更好的音色 |

### 12.1 音频缓存策略

```typescript
const audioCache = new Map<string, string>()

const playWithCache = async (text: string) => {
  if (audioCache.has(text)) {
    playAudio(audioCache.get(text)!)
  } else {
    const url = await fetchTTS(text)
    audioCache.set(text, url)
    playAudio(url)
  }
}
```

### 12.2 限流保护

```typescript
let lastRequestTime = 0
const RATE_LIMIT_MS = 1000

const throttledTTS = async (text: string) => {
  const now = Date.now()
  if (now - lastRequestTime < RATE_LIMIT_MS) {
    await sleep(RATE_LIMIT_MS - (now - lastRequestTime))
  }
  lastRequestTime = Date.now()
  return fetchTTS(text)
}
```

### 12.3 Spaced Repetition 复习机制（v1.2+）

```typescript
/**
 * 基于艾宾浩斯遗忘曲线的复习间隔
 * 用于薄弱项自动进入复习池
 */
const calculateNextReview = (correctCount: number): Date => {
  const intervals = [1, 3, 7, 14, 30] // 天
  const index = Math.min(correctCount, intervals.length - 1)
  return dayjs().add(intervals[index], "day").toDate()
}
```
