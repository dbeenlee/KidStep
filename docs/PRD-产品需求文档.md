## 一、产品概述

### 1.1 产品背景

#### 市场背景
- 2022年教育部新课标实施，明确一年级"零起点"教学
- 2026年教育部新规：一年级设置不少于4周入学适应期
- 幼儿园大班家长对幼小衔接焦虑度持续上升
- 市面产品要么偏商业课程，要么仅有单一打卡功能，缺乏系统性工具

#### 用户痛点
| 痛点 | 现状 | 期望 |
|------|------|------|
| 知识碎片化 | 网上信息杂乱，不知信哪个 | 权威、系统、易懂 |
| 不知怎么做 | 知道重要但无从下手 | 清晰的步骤和工具 |
| 难以坚持 | 三分钟热度，缺乏监督 | 简单打卡、持续激励 |
| 效果难评估 | 不知道孩子进步没有 | 可视化进度、对比 |
| 焦虑传递 | 家长的焦虑影响孩子 | 科学的认知、平和心态 |

### 1.2 产品定义

**产品名称**：童行（KidStep）

**一句话描述**：帮助幼儿园大班家长科学开展幼小衔接的"教练工具"

**Slogan**：每一步，都陪你走

**核心价值**：
- 家长从"焦虑"到"从容"
- 孩子从"零准备"到"准备好"

> 📌 品牌方案详见：[品牌命名方案-2026-05-22.md](./品牌命名方案-2026-05-22.md)

### 1.3 产品目标

| 类型 | 目标 | 指标 |
|------|------|------|
| 业务目标 | 帮助家长科学准备 | 知识掌握率 > 80% |
| 业务目标 | 提升孩子入学适应速度 | 适应周期缩短 50% |
| 用户目标 | 降低家长焦虑感 | 用户满意度 > 90% |
| 用户目标 | 养成每日习惯 | 连续打卡率 > 60% |

### 1.4 产品范围

#### 包含范围
- 知识学习：系统的幼小衔接知识体系
- 能力评估：四个维度的科学评估工具
- 训练计划：三阶段渐进式训练方案
- 习惯养成：每日打卡与激励机制
- 成长记录：里程碑事件与档案管理

#### 不包含范围
- 正式课程教学
- 在线直播课
- 1v1 辅导服务
- 幼儿园/小学对接服务

## 二、用户画像

### 2.1 目标用户

#### 核心用户：幼儿园大班家长

**用户A：小美妈妈（职场妈妈）**
- 年龄：32岁
- 职业：上班族，朝九晚六
- 痛点：没时间研究，但很焦虑
- 行为：碎片化使用，通勤时看文章，晚上陪孩子做任务
- 期望：简单高效，不需要太花时间

**用户B：大鹏爸爸（全职爸爸）**
- 年龄：35岁
- 职业：全职带娃
- 痛点：愿意投入但不知道方法对不对
- 行为：深度学习，认真执行每个任务
- 期望：专业权威，有理论支撑

**用户C：阿华爷爷/奶奶（祖辈带娃）**
- 年龄：55-60岁
- 痛点：手机操作不熟练，视力不太好
- 行为：需要简化操作
- 期望：够大够简单

### 2.2 用户使用场景

| 场景 | 时间 | 行为 | 需求 |
|------|------|------|------|
| 地铁通勤 | 早上30分钟 | 看一篇知识文章 | 短小精炼，有收获感 |
| 午休时间 | 中午15分钟 | 打卡今日任务 | 3秒完成，快速打卡 |
| 晚上陪娃 | 19:00-20:00 | 做训练任务 | 有步骤指引，有示范 |
| 周末 | 全天 | 系统学习/户外活动 | 完整训练方案 |
| 入学前1周 | 全天 | 冲刺准备 | 清单 checklist |

### 2.3 用户决策路径

```
家长痛点 → 搜索"幼小衔接" 
         → 看到小程序分享/推荐 
         → 扫码进入 
         → 初次评估 
         → 获得个性化方案 
         → 每日使用 → 坚持打卡 → 孩子顺利入学 → 口碑传播
```

## 四、功能详述

### 4.1 首页（今日）

#### 4.1.1 功能概述
首页是用户每日打开的"仪表盘"，展示当日核心任务和整体进度。

#### 4.1.2 功能点

**A. 今日任务卡片**
| 字段 | 说明 |
|------|------|
| 标题 | "今日任务" |
| 内容 | 今日3-5项任务清单 |
| 任务类型 | 习惯打卡/能力训练/知识学习 |
| 操作 | 点击→跳转任务详情 / 勾选→标记完成 |

**交互细节**：
- 默认展示当日最重要的3个任务
- 点击"查看全部"展开完整列表
- 完成打卡后，卡片变绿 + 撒花动画
- 未完成任务橙色提示

**B. 快速打卡入口**
| 字段 | 说明 |
|------|------|
| 布局 | 3个快捷按钮横排 |
| 按钮 | 起床打卡🏃 / 阅读打卡📖 / 运动打卡⚽ |
| 操作 | 点击即打卡，无需确认 |

**交互细节**：
- 点击后按钮变绿 + 打卡成功提示（1秒后消失）
- 已打卡按钮显示✓标记
- 长按可查看打卡详情

**C. 能力雷达图**
| 字段 | 说明 |
|------|------|
| 类型 | 雷达图（五维） |
| 维度 | 身心/生活/社会/学习/综合 |
| 数据 | 来自最近一次评估（四周内） |
| 操作 | 点击→跳转评估详情 |

**交互细节**：
- 无评估数据时显示引导"点击开始首次评估"
- 雷达图可交互，点击某个维度高亮
- 颜色渐变：红色(0-40) → 橙色(40-70) → 绿色(70-100)

**D. 知识速递**
| 字段 | 说明 |
|------|------|
| 布局 | 单条卡片 + 左右滑动 |
| 内容 | 今日知识小贴士（200字内） |
| 来源 | 系统每日推送 |
| 操作 | 点击→跳转文章详情 |

**E. 成长进度**
| 字段 | 说明 |
|------|------|
| 指标 | 连续打卡天数、评估次数、已学知识 |
| 布局 | 3个数字横排 |
| 操作 | 点击→跳转对应页面 |

**F. 欢迎语（动态）**
| 时段 | 欢迎语 |
|------|--------|
| 早上 | "早起的鸟儿有虫吃~" |
| 白天 | "今天也要加油哦" |
| 晚上 | "陪孩子完成今日任务吧" |
| 周末 | "周末正是亲子时光~" |

### 4.3 能力评估

#### 4.3.1 功能概述
帮助家长科学评估孩子在四个维度的准备情况，生成个性化建议。

#### 4.3.2 功能点

**A. 评估向导**
| 步骤 | 内容 |
|------|------|
| Step 1 | 欢迎页 + 评估说明 |
| Step 2 | 选择孩子（如有多个） |
| Step 3 | 选择评估维度 |
| Step 4 | 开始答题 |
| Step 5 | 查看结果 |

**评估维度选项**：
| 维度 | 题数 | 时长 |
|------|------|------|
| 身心准备 | 10题 | 3分钟 |
| 生活准备 | 10题 | 3分钟 |
| 社会准备 | 10题 | 3分钟 |
| 学习准备 | 10题 | 3分钟 |
| 全部评估 | 40题 | 10分钟 |

**B. 答题界面**
| 字段 | 说明 |
|------|------|
| 进度条 | 当前题/总题数 |
| 题目 | 单选/多选题 |
| 选项 | 4个选项，图标+文字 |
| 操作 | 上一题、下一题、跳过 |

**题目示例**：
```
孩子是否能独立完成以下事情：
□ A. 完全独立完成，不需要提醒
□ B. 偶尔需要提醒
□ C. 需要较多帮助
□ D. 完全依赖成人
```

**题型分类**：
| 题型 | 描述 | 占比 |
|------|------|------|
| 行为观察 | 询问孩子日常表现 | 60% |
| 知识问答 | 简单知识测试 | 20% |
| 情景模拟 | 假设场景选择 | 20% |

**C. 评估结果页**
| 区块 | 内容 |
|------|------|
| 总分展示 | 雷达图 + 综合评分 |
| 分项得分 | 四个维度分别展示 |
| 优势分析 | 得分最高的2-3项 |
| 待提升项 | 得分最低的2-3项 |
| 详细报告 | 每题回答 + 分析 |
| 个性化建议 | 基于薄弱项的3-5条建议 |
| 下次建议 | 何时再次评估 |

**雷达图交互**：
| 操作 | 响应 |
|------|------|
| 点击维度 | 展开该维度详细分析 |
| 长按维度 | 显示该维度题目答案 |
| 滑动 | 360°旋转查看 |
| 截图 | 支持保存到相册 |

**D. 历史记录**
| 功能 | 说明 |
|------|------|
| 列表 | 按时间倒序 |
| 对比 | 两次评估结果对比 |
| 趋势 | 得分变化曲线图 |

**E. 进步报告**
| 功能 | 说明 |
|------|------|
| 月度报告 | 每月自动生成 |
| 内容 | 本月评估对比 + 成长总结 |
| 分享 | 支持分享到微信 |

### 4.4 训练计划

#### 4.4.1 功能概述
基于评估结果，生成个性化的三阶段训练计划，配套每日任务推送。

#### 4.4.2 功能点

**A. 阶段概览**
| 阶段 | 时间 | 核心目标 | 任务数/天 |
|------|------|---------|----------|
| 第一阶段 | 入学前3个月 | 习惯建立、兴趣培养 | 3-5个 |
| 第二阶段 | 入学前1个月 | 知识巩固、模拟训练 | 4-6个 |

## 九、开发路线图

> 基于"先跑最小功能集，看数据再迭代"的原则

---

### 9.0 Web MVP - 极简版（目标：1-2周完成）

**核心理念**：先跑起来，再迭代。不要想太多规则，先让用户能用起来。

**必须功能（4个）**：

| # | 功能 | 说明 | 优先级 |
|---|------|------|:------:|
| 1 | **账号注册/登录** | 手机号+验证码，最简登录 | P0 |
| 2 | **孩子信息管理** | 姓名、生日、目标学校 | P0 |
| 3 | **能力评估问卷** | 4维度40题，生成雷达图报告 | P0 |
| 4 | **每日打卡** | 3个快捷打卡 + 自定义打卡 | P0 |

**可选功能（按需添加）**：

| # | 功能 | 说明 | 优先级 |
|---|------|------|:------:|
| 5 | 打卡日历 | 查看历史打卡记录 | P1 |
| 6 | 成长进度 | 连续打卡天数、本周打卡率 | P1 |
| 7 | 知识文章（5篇） | 先放5篇核心文章测试 | P2 |

**MVP不做**：
- ❌ 训练计划（先让用户自己玩）
- ❌ 积分体系（先跑起来再想激励）
- ❌ 家长端/孩子端分离（先单端验证）
- ❌ 图片识别（技术成本高）
- ❌ 语音录入（同上）

## 十一、竞品分析与产品迭代

> 基于 joye-preschool + 公众号文章《我用 OpenClaw 给女儿搭了一套学习系统》的深度分析

### 11.1 joye-preschool 项目分析

**项目定位**：专为6岁幼小衔接儿童设计的综合启蒙学习应用，涵盖数学、拼音、英语三大模块。

#### ✅ 优点（值得借鉴）

| 优点 | 说明 | 可借鉴点 |
|------|------|---------|
| 多感官学习设计 | 拼读动画、颜色区分 | 可借鉴到营养知识颜色区分 |
| 题型多样化 | 多种题型组合 | 任务类型多样化 |
| 语音混合方案 | TTS + Web Speech API | 语音播报策略 |
| 闯关模式 + 星评 | 入门/进阶/挑战 + 1-3星 | 打卡激励 |
| 错题本 | 自动收集错题 | 薄弱项进复习池 |
| 收藏夹 | 收藏难记的项 | 收藏困难任务 |

#### ❌ 缺点（需避免）

| 缺点 | 改进方案 |
|------|---------|
| 纯 localStorage，无后端 | 必须有后端 API |
| 无家长/孩子端分离 | 必须做账号隔离 |
| 无家长监控面板 | 必须有家长管理后台 |
| 无单任务模式 | 一次只出一题 |
| 无积分/成就可视化 | 引入积分连续打卡体系 |
| 无智能复习机制 | 必须有 Spaced Repetition |
| 无主动推送 | 微信订阅消息/推送 |
| 无语音输入 | 语音识别输入 |
| 无图片识别 | 拍照识别 |

### 11.2 OpenClaw 学习系统实践

**核心洞察**：用 AI Agent 给女儿搭建个性化学习系统，效果显著。

#### ✅ 可借鉴的核心理念

| 理念 | 原文核心 | 落地到产品 |
|------|---------|---------|
| Agent 主动推送 > 被动问答 | "ChatGPT 是你问它答，OpenClaw 是你设计规则" | 系统主动推今日任务 |
| 账号隔离 | Grace 只能在自己频道做题；爸爸有独立管理频道 | 家长端 vs 孩子端权限分离 |
| 积分"被看见" | "永远不扣分" | 打卡积分只奖不扣；即时反馈 |
| 单任务模式 | "一次性出五题她看到就烦，改成单题后意犹未尽" | 每次只展示一个待办任务 |
| 数据驱动调整 | "打开表格就知道孩子学了什么、哪些反复出错" | 自动汇总周报/月报趋势图 |
| 图片识别录入 | "拍课本自动识别整理" | 拍照识别食物/药品 |
| 规则迭代 | "先跑最简单的版本，看孩子反应再慢慢加规则" | MVP先上，快速迭代 |

#### ❌ 踩过的坑

| 坑 | 问题 | 改进 |
|------|------|------|
| 飞书工具 schema 过大 | 每次请求都发一遍导致响应慢 | 只启用必要的工具 |
| 规则想太多 | 一开始想把所有规则都设计好再上线 | MVP 先跑，根据数据迭代 |
| 数据归一化没做 | 题库越来越乱 | 数据入库前必须做归一化处理 |
| 高估文字耐心 | 操作链路太长被砍 | 操作步骤≤3步 |

### 11.3 综合设计原则

#### 🎯 核心理念

1. **主动推送 > 被动查询**：系统按规则主动安排任务，用户不需要想"今天做什么"
2. **账号隔离**：家长是规则设计者，孩子是执行者，权限分明
3. **极简操作**：≤3步完成一个动作，不等待
4. **积分即反馈**：只奖不扣，每次努力都被记录
5. **数据驾驶舱**：让进步可视化，打开就能看清状态

#### 📱 交互原则

| 原则 | 具体做法 |
|------|---------|
| 单任务模式 | 每个时刻只展示1个待办，完成后展示下一个 |
| 3秒打卡 | 点击即完成，无需确认 |
| 即时反馈 | 完成就撒花/积分动画，不延迟 |
| 连续激励 | 连续N天 +N分（上限+7），永远不扣 |
| 图片录入 | 拍照自动识别，不手动填 |
| 语音录入 | 一键语音记录，不打字 |

### 11.6 差异化定位

**joye-preschool** = 儿童自主学习工具（孩子自己操作）

**本文方案** = 家长主导的孩子成长管理系统（家长设计，孩子执行，系统主动推进）

核心差异：**家长是设计者，系统是执行者，孩子是被服务者** —— 这与 OpenClaw 给女儿搭建学习系统的理念一致。
